# صفحة روابط تلاوات شادي

## الملفات
| الملف | الوظيفة |
|---|---|
| `links.js` | الروابط. أضف أو احذف أو رتّب من هنا |
| `index.html` | محتوى الصفحة: الاسم، النبذة، الآية، كود الإحصائيات |
| `style.css` | الألوان والخطوط والحركات |
| `assets/` | الخطوط، أيقونات المنصات، أيقونة المتصفح، صورة معاينة الرابط |

## إضافة رابط جديد
1. ضع أيقونته (SVG) في `assets/icons/`. أيقونات المنصات متوفرة مجانًا في simpleicons.org.
2. أضف سطرًا في `links.js` بنفس شكل الأسطر الموجودة.

## النشر على GitHub Pages
1. افتح الـ Repository `tilawatshadi.github.io`.
2. **Add file ← Upload files**، واسحب **محتويات** المجلد (لا المجلد نفسه)، ثم **Commit changes**.
3. **Settings ← Pages**: في Source اختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة أو دقيقتين تفتح الصفحة على `https://tilawatshadi.github.io`.

لتعديل ملف لاحقًا: افتحه في GitHub واضغط أيقونة القلم، أو ارفع النسخة الجديدة بنفس الاسم.

## الإحصائيات (GoatCounter)
1. سجّل في goatcounter.com واختر الكود `tilawatshadi`.
2. إذا اخترت كودًا آخر، عدّله في آخر `index.html`.
3. الزيارات والضغطات على كل زر تظهر في لوحة `tilawatshadi.goatcounter.com`.
